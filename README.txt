1. Copy this folder to htdocs (XAMPP) as africa-scholarships.
2. Edit config.php (database login, SITE_URL, later ADSENSE_CLIENT and ADSENSE_SLOT).
3. Open http://localhost/africa-scholarships/install.php, create your admin, then DELETE install.php.
4. Log in at /admin/login.php. All 50 listings have no deadline set: confirm each on its official site and add it in admin.
5. Send newsletters with Brevo or Mailchimp using the CSV from admin > Subscribers.
